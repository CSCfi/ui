# CDatePicker

We want to add a date picker component

## Features

- Features and design should be based on the Material Design 3 Data Picker, but match the design of the other components in the csc-ui
- the picker should open under an input in a popover on desktop and fullscreen on mobile just like CAutocomplete, CSelect, and CTreeSelect
- The picker should be accessible and keyboard operable
  - the input should be fillable by typing without using the popover
- The date format should be configurable through a prop
- Start of the week should be configurable
- it should support date range selection
- it should support disabling dates / date ranges
