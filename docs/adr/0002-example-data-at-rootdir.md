# Keep `example-data/` at the docs package root, not inside `app/`

When migrating `csc-ui-documentation` to Nuxt 4 (which moves Vue source into `app/` as the new `srcDir`), `example-data/` was deliberately left at the package root and its consumers updated to reference it via the `~~/` (rootDir) alias. The directory holds 44 folders of `*.script.js` / `*.template.js` files that are pre-processed by [`scripts/build-examples.js`](../../packages/csc-ui-documentation/scripts/build-examples.js) before each dev/build run; treating it as build input rather than Vue source draws a clean line between `app/` (hand-written framework code) and root-level pipelines (`scripts/` produces `example-data/`, which `app/` reads). The alternative — moving it into `app/example-data/` so existing `../example-data/` relative paths stayed unchanged — would have preserved a smaller diff but put generated content inside `srcDir`, which makes the meaning of `app/` ambiguous for the next contributor adding examples.
