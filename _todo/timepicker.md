# CTimePicker
we'd like to create a time picker component

- the component should be similar to the CDatePicker (input & popover)

## Features
- 24h / 12h support
- should consist of 2 scrollable side by side lists (hour & minute)
  - 3 lists for 12h version (hour, minute, and am/pm)
- The picker should be accessible and keyboard operable
  - the input should be fillable by typing without using the popover
